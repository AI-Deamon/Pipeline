## Phase 1: Critical Security Fixes (Immediate)

### 1.1 Auth Bypass via `/callback` Path Matching
- **File**: `backend/app/core/auth.py:25-27`
- **Issue**: `request.url.path.endswith("/callback")` grants fake user to ANY path ending in `/callback`
- **Fix**: Replace with exact route matching against registered callback endpoints
```python
# BEFORE
if request.url.path.endswith("/callback"):
    return type("User", (), {"username": "callback-bypass"})()

# AFTER
CALLBACK_ROUTES = {"/api/v1/scans/callback", "/api/v1/projects/{project_id}/scans/callback"}
if request.url.path.rstrip("/") in {r.split("{")[0].rstrip("/") for r in CALLBACK_ROUTES}:
    # Only allow exact registered callback paths
    ...
```
Actually, the correct fix is to check if the route is *registered* as a callback route using FastAPI's router metadata, or use an explicit allowlist:
```python
CALLBACK_PATH_PREFIXES = ("/api/v1/scans/callback",)
if any(request.url.path.rstrip("/").endswith(p) for p in CALLBACK_PATH_PREFIXES):
    return type("User", (), {"username": "callback-bypass", "id": None, "role": None})()
```
**Better**: Remove the path-based bypass entirely and use a proper `Depends` for callback auth that validates the callback token.

### 1.2 API Key Auth Returns Fake User Without DB Record
- **File**: `backend/app/core/auth.py:30-33`
- **Issue**: Returns `type("User", (), {"username": "api-key-bypass"})()` — no `id`, no `role`, breaks RBAC
- **Fix**: Load or create a service account from the database:
```python
if api_key and api_key == settings.API_KEY:
    service_user = db.query(UserDB).filter(UserDB.username == "service-account").first()
    if not service_user:
        service_user = UserDB(username="service-account", role="admin", is_active=True)
        db.add(service_user)
        db.commit()
        db.refresh(service_user)
    return service_user
```

### 1.3 JWT Fallback to API_KEY
- **File**: `backend/app/core/security.py:11-20`
- **Issue**: JWT signing key falls back to `API_KEY` when `JWT_SECRET_KEY` is not set
- **Fix**: Generate a random key at startup if not configured, log a warning:
```python
if settings.JWT_SECRET_KEY:
    SECRET_KEY = settings.JWT_SECRET_KEY
else:
    SECRET_KEY = secrets.token_hex(32)
    warnings.warn("JWT_SECRET_KEY not set — generated ephemeral key. Tokens will not survive restart.")
```

### 1.4 Path Traversal in Code Snippet Endpoint
- **File**: `backend/app/api/projects.py:241-330`
- **Issue**: `workspace / file` with no sanitization allows `../../etc/passwd`
- **Fix**:
```python
file_path = (workspace / file).resolve()
if not file_path.is_relative_to(workspace.resolve()):
    raise HTTPException(status_code=403, detail="Access denied")
```

### 1.5 Reports Endpoints Missing Project Ownership
- **File**: `backend/app/api/reports.py:205-232`
- **Issue**: `download_raw_report` and `delete_report` lack project ownership verification

### 1.6 WebSocket Endpoints Have No Authentication

### 1.7 Path Traversal in Nmap Scanner
