# Plan: Improve Manager/Executive Dashboard

## Objective
Enhance the existing manager-focused dashboard with cross-project visibility, trend analysis, team metrics, and executive summaries.

## Current State

| Page | What It Shows | Limitation |
|------|---------------|------------|
| DashboardPage | Project list with severity dots | No cross-project comparison |
| UnifiedReportPage | Charts + risk score per project | No historical trends |
| ProjectReportsPage | Per-scan details | No team/workload view |
